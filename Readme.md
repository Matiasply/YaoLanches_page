# Yao Lanches Landing Page 🍕🌭🥪

## Melhor lanche e almoço do CI!

Bem-vindo ao repositório do projeto "Yao Lanches Landing Page"! Este projeto é uma página de destino (landing page) para o restaurante Yao Lanches, que oferece uma variedade de deliciosos lanches, incluindo pizzas, hot dogs e sanduíches. O melhor lanche e almoço do Centro de Informática da Universidade Federal da Paraíba! 

## Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando Next.js, uma estrutura de desenvolvimento React que permite a criação de aplicações web rápidas e eficientes. A escolha do Next.js foi motivada por suas funcionalidades avançadas, como renderização do lado do servidor (SSR) e geração de sites estáticos (SSG), que garantem uma experiência de usuário fluida e otimizada.
